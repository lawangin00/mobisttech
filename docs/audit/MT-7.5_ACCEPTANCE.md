Other subsequent gates were skipped, so no remote complete acceptance was claimed.
- Local `withoutExceptionHandling()` diagnosis traced the 404 to `WebsiteCms::saveSoftwareDraft()` looking up a non-existent Software public ID at line 410. This is an actual existing target HTTP route binding defect, not an absent route, CSRF bypass or missing software permission.
- Material fix reads only the named `$request->route('software')` parameter in the controller, treating an omitted Software ID as null; authenticated update retains its explicit Software ID. An isolated published Website-mode test fixture ensures that the initial unpublished Software API 404 is genuinely draft isolation rather than an unpublished site. Two deterministic three-character test outlet codes avoid unrelated fixture-code collisions.
